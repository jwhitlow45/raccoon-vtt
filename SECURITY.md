# Security policy

## Supported versions

Only the latest release receives security fixes. Self-hosters should follow
the README's [Updating](README.md#updating) section to keep their installation
current.

## Report a vulnerability

Use GitHub's private vulnerability reporting: open this repository's
**Security** tab and choose **Report a vulnerability**. Never report a
vulnerability in a public issue.

Include the affected version, what you found, steps to reproduce it, the
expected impact, and a minimal proof of concept if possible. Remove passwords,
room links and other private data from logs and screenshots.

Reports receive a reply. A fix ships before the vulnerability's details are
made public. Please keep the report private while the fix is being prepared.
